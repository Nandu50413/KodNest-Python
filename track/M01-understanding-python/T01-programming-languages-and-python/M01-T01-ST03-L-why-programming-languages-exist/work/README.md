1. Why does a computer need instructions?
A computer has no brain of its own to think or guess—it only does what we explicitly tell it to do, step by step.

2. Why is normal human language not enough for writing computer programs?
Human language is flexible and can have multiple meanings depending on context, while a computer needs exact rules with zero confusion.

3. What does a computer ultimately execute?
A computer ultimately executes machine language (binary code made of 0s and 1s).

4. Why is writing complete applications in machine language difficult?
Reading, writing, and fixing errors in long strings of 0s and 1s is too slow and confusing for humans.

5. How does a programming language act as a bridge?
It lets humans write instructions in readable words and symbols, which a translator (interpreter/compiler) converts into binary 0s and 1s for the computer.

6. Why do programming languages have syntax rules?
Syntax rules keep code structured and unambiguous so the computer knows exactly how to read and translate every line without errors.

7. How do programming languages make complex applications manageable?
They let developers break big problems into smaller, readable parts (like variables, functions, and files) that are easy to test, fix, and reuse.

8. What is the difference between a requirement, logic, and code?
	• Requirement: What the program needs to achieve (e.g., "Check if percentage is at least 60").
	• Logic: How to solve it step by step in plain thinking (e.g., "Compare percentage with 60 and decide eligibility").
	• Code: Writing that logic using a programming language's exact syntax (e.g., if percentage >= 60:)
